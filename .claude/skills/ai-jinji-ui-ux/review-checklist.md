# UI 変更 必須セルフレビュー — AI人事24h

**UI を実装/修正したら、"完了" と言う前にこのチェックを上から通す。**
P0/P1/P2 相当の UI/UX 問題が残るなら**完了扱いにしない**（修正 or 明示的に報告）。

## 深刻度の目安
- **P0（絶対に出さない）**: 他社/他人データが見える・PII 漏洩・破壊操作の誤爆・XSS・虚偽表示（ダミーを実データ風/未実装を動作中に見せる）・キーボードで操作不能・本番で壊れる。
- **P1**: 迷子になる導線・色だけの状態・無効理由不明・empty/error 欠如・モバイル横スクロール/重なり・コントラスト不足・保存結果の無フィードバック。
- **P2**: 一貫性の乱れ（色/radius/status表現）・過剰装飾・軽微な余白/階層のズレ・reduced-motion 未対応。

## A. UX / 導線
- [ ] この画面の**主目的が 1 つ**で、Primary action が乱立していない。
- [ ] 次に何をすればいいかが**一目で分かる**（面接なら「何が起きているか/話していいか/次に何を」）。
- [ ] **操作結果が即 feedback**（保存/更新は toast or インライン）。押して無反応がない。
- [ ] **disabled の理由が近くに分かる**。理由不明の無効がない。
- [ ] 破壊/不可逆操作だけ確認を出し、可逆操作に確認を乱用していない。破壊操作が主動線と分離。

## B. Visual hierarchy / Consistency
- [ ] 重要情報ほど視覚階層が上（サイズ/太さ/位置/コントラスト）。巨大タイトル乱用なし。
- [ ] 色/radius/shadow/ボタン階層が **design-system.md** に沿う（neutral は slate、button radius は `rounded-lg`、card は `rounded-2xl shadow-sm`）。
- [ ] 同じ意味の **status/日付/金額表記が全画面で同一**（応募者 status は `displayStatus` 再利用）。
- [ ] 過剰 gradient/shadow なし、カード in カードなし、border だらけなし、**AI紫グラデなし**。

## C. Responsive
- [ ] 320 / 375–390 / tablet / 13"MacBook / Windows laptop / large で崩れない。
- [ ] **横スクロール前提でない**（テーブルは列優先度で stack/hide/collapse）。
- [ ] 固定要素（面接の小窓/バー等）が本文と**重ならない**。
- [ ] PC UI の単純縮小でなく、情報優先順位で再構成。

## D. Accessibility（accessibility.md）
- [ ] **キーボードだけで操作完結**、Tab 順が自然、モーダルはトラップ+Esc。
- [ ] **focus が見える**（`focus-visible:ring-2 ring-blue-500`）。outline を素で消していない。
- [ ] アイコンのみボタンに `aria-label`、装飾アイコンは `aria-hidden`。トグルは `aria-pressed` 等。
- [ ] **色だけで状態を伝えていない**（テキスト/記号/形を併用）。
- [ ] コントラスト AA（本文に `slate-300/400` を使っていない）。
- [ ] 動的更新に live region、フォームは label + error 関連付け。
- [ ] `prefers-reduced-motion` 尊重。タッチ target ≥44px、hover 前提でない。

## E. 状態網羅
- [ ] **Loading**: レイアウトが跳ねない。**虚偽進捗を出していない**（存在しない処理を loading にしない）。
- [ ] **Empty**: 正直な文言 + 可能なら次アクション。**ダミー/synthetic を空状態代わりにしていない**。
- [ ] **Error**: 「何が起きたか + 次に何を」。**PII/生 message を出していない**。再試行導線あり。

## F. テキスト堅牢性
- [ ] **長文/改行/記号/URL/HTMLっぽい文字列**でも崩れず安全表示（`break-words` + `whitespace-pre-wrap`、`dangerouslySetInnerHTML` 不使用）。
- [ ] **日本語**（長い氏名/助詞/禁則）で折返し破綻なし。
- [ ] **多言語**（en/vi/zh/ne/pt）でボタン/ラベルが溢れない。

## G. 正直な UI / データ境界（このプロダクトの最重要）
- [ ] **ダミー/synthetic を実データのように表示していない**（本番は空状態）。
- [ ] **未実装機能を操作可能に見せていない**（"録画中"等の虚偽なし）。
- [ ] **PII をログ/URL/error/analytics に出していない**。表示は React 既定エスケープのみ。
- [ ] 認可境界を UI で崩していない（自社/自分スコープのみ、ID 直打ち導線なし、service-role 非露出）。

## H. 非回帰
- [ ] 既存の認可/状態管理/API/responsive/a11y を壊していない。
- [ ] 「Skill と違うから」だけで無関係な既存 UI を書き換えていない（変更は現状→問題→改善理由→変更で説明可能）。
- [ ] 新 UI ライブラリを増やしていない。既存トークン/コンポーネントを再利用。

## I. ビルド/型（該当時）
- [ ] `eslint` 追加問題なし / `tsc --noEmit` clean / `npm run build` 成功。UI ロジックは純関数に分離して vitest（RTL/jsdom を新規導入しない）。
